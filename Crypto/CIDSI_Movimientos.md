# CIDSI - Movimientos

## Descripción

Desempolvando los pasos desde los 90'.

Formato de la flag:

```text
cidsi{flag_en_md5}
```

Se proporciona una imagen donde aparecen varias personas realizando movimientos de baile.

---

## Análisis

Al analizar la imagen se identificó que los movimientos representaban una secuencia codificada.

Utilizando la herramienta dCode para interpretar la secuencia se obtuvo:

```text
REKLAWNOOM
```

Observando el resultado se detectó que se encontraba invertido.

Al invertir la cadena se obtiene:

```text
MOONWALKER
```

Posteriormente se convierte a minúsculas:

```text
moonwalker
```

Finalmente se calcula el hash MD5.

---

## Procedimiento

Texto recuperado:

```text
moonwalker
```

MD5:

```text
67192ced7898f434effd7c841c83e930
```

---

## Flag

```text
cidsi{67192ced7898f434effd7c841c83e930}
```
